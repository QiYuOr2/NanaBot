# 0011 site 移动端导航抽屉

- **状态**：已完成
- **日期**：2026-11-12
- **影响范围**：`apps/site`
- **关联需求**：移动端无法切换页面，需要可展开的侧边栏。
- **关联条目**：[上一条](./0010-site-qq-test-messages.md) · [返回概览](./README.md)

## 背景

页面外壳的侧边栏一直以 `lg:flex` 显示，小屏下直接隐藏，但顶栏没有替代入口，移动端只能停留在当前页面。布局与顶栏已经抽成 `layouts/default.vue` 和 `AppHeader.vue`，适合在现有外壳上补导航，不改各页面结构。

## 关键决策与取舍

- 使用浏览器原生 `dialog.showModal()`：直接获得模态语义、背景不可交互与 Esc 行为，避免手写焦点陷阱。
- 抽屉状态放 Nuxt `useState`：服务端渲染不会共享全局单例，顶栏按钮能直接控制抽屉。
- 抽屉复用 `AppSidebar`：导航项、当前页高亮与账号信息只有一份，避免桌面 / 移动两套菜单漂移。
- 关闭时恢复 `documentElement` 的 `overflow`，并在路由变化时兜底关闭，防止切页后背景仍被锁住。

## 兼容性与数据安全

- 仅调整页面外壳与交互，不改变接口、配置或存储结构。
- 桌面端布局、导航链接与页面内容保持不变。
- 未启用 JavaScript 时仍有顶栏与页面内容，但抽屉无法展开（与原生 dialog 一致）。
