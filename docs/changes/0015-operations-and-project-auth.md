# 0015 运维面板、项目鉴权与账号控制

- **日期**：2026-11-12
- **影响范围**：site、bot、共享配置 / 常量 / 工具、CI 与部署检查。

## 行为变化

| 功能            | 行为                                                                                                              |
| --------------- | ----------------------------------------------------------------------------------------------------------------- |
| site CI         | 仅 site、其依赖包、共享构建输入、部署脚本或 workflow 变化时自动运行；保留手动触发                                 |
| 上线 / 下线提醒 | `botNotifications.online/offline.enabled` 独立开关，`messageTemplate` 自定义文案；上线默认“我来了~”，不追加账号名 |
| 账号停用        | `accounts[].enabled: false` 跳过连接、监控、录制和推送，不改发到其他账号；支持全部停用                            |
| NapCat 看门狗   | `accounts[].napcat.watchdog` 默认 false，关闭主动探活、强制重连和库自动重连；true 恢复原行为                      |
| 日志页          | `/logs` 按需读取根目录 `logs/` 下日志及轮转文件的末尾内容，支持账号子目录与手动刷新                               |
| 服务器状态      | `/system` 每次进入或刷新获取 CPU、内存、交换空间、可见磁盘与 NVIDIA GPU 数据，不轮询                              |
| 全站登录        | 业务页面与 API 统一鉴权，登录一次记住 30 天，侧栏退出；QQ 设置页共用会话                                          |

## 配置与迁移

项目根目录 `.env` 的 `NANA_AUTH_TOKEN` 是统一口令（至少 16 位）。优先读取进程中的同名变量，
再读取根目录文件，最后兼容原 `apps/site` / `apps/bot` 的 `NANA_SITE_CONFIG_TOKEN`。
读取收口到 `@nana/utils.readProjectAuthToken`，bot 控制接口与 site 使用同一规则。
部署时需自行提供被 gitignore 的根目录 `.env`。更换口令后旧会话立即失效。

Cookie 包含到期时间、随机数与 HMAC 签名，不保存原口令；设置 HttpOnly、SameSite=Lax，
HTTPS 时加 Secure。登录失败有次数限制，写请求拒绝跨站来源。仅登录状态 / 登录 / 退出以及
`/api/health` 为公开 API，健康检查不返回业务数据，部署脚本改用该接口。
词云图片响应也使用 `no-store`，不再覆盖鉴权中间件的缓存限制。

提醒模板支持 `{accountId}`、`{accountName}`、`{provider}`，目标仍是各账号管理群。
提醒和账号配置在 bot 启动时读取，修改后需重启；群映射仍按发送时读取，无需重启。
NapCat 服务已停用时推荐直接设置账号 `enabled: false`，避免首次连接也产生等待与错误。

上线提醒在每个账号本次进程首次就绪时发送一次；官方 QQ 的 READY / RESUMED 以及 NapCat
重连仍正常广播连接状态，供离线告警判断恢复，但不会重复发送上线消息。
官方连接日志补充 SDK 的断开原因和恢复耗时，可区分网关要求重连、无效会话及远端关闭。
`1000` 本身不足以确定根因：SDK 在处理网关 opcode 7 / 9 时也使用该码。
2026-11-12 的两次日志都收到 RESUMED，且早于 13:16:19 的 token 到期时间，
未显示持续掉线或鉴权失效；官方文档未承诺每小时断开一次，不添加定时重启或额外重连循环。

## 运维边界

日志只列出真实目录中的 `.log`、`.txt`、`.out`、`.err` 及数字轮转文件，跳过符号链接，
拒绝目录穿越；单次最多 256 KiB / 2000 行，目录递归最多 5 层 / 500 个文件。
系统状态来自 site 所在运行环境。Linux 内存按 MemAvailable 计算，磁盘按文件系统去重；
GPU 通过有超时的 `nvidia-smi` 调用采集，未安装或失败时独立降级，其余指标继续显示。

补齐 Golar + Vue 插件，使已有 `nuxt typecheck` 在 TypeScript 7 工具链下可运行。
类型检查发现并修复了既有词频组件误读 `stats.topWords` 的问题，改用实际 `topWords` prop。
